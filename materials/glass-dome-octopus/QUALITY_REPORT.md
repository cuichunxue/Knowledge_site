## 2. 計測方法

**参考画像（手作業）：** 50px の格子を重ねた拡大画像から読み取りました。輪郭は ±5px、触手の長さは節の中心を結ぶ折れ線で ±10%。

| 量 | 参考画像（px） | 読み取り位置（元画像の座標） |
|---|---|---|
| 本体（ガラス球）直径 | 352 | x 660〜1012 |
| 全体の幅 / 高さ | 995 / 635 | 触手の先端 x 335〜1330 / ドーム頂点 y 95〜最下部の先端 y 730 |
| ドームの見える高さ | 215 | ガラス頂点 y 95 〜 左右の輪郭での装甲上端 y ≈ 310 |
| 触手の付け根の径 | 80 | 手前中央の触手、本体の直下 |
| カメラ：白いハウジング / レンズ | 125 / 82 | 中心 (712, 372) |
| 先端の巻きの径 | 85 | 右上に持ち上がった触手の先端 |
| 触手の画面上の長さ | 525 / 425 / 309 | 右上の持ち上げ / 左の横向き / 手前中央 |

**レンダリング（自動）：** `tools/measure_render.mjs` が、モデル自身の寸法をヒーローカメラで画面に投影して計算します（`src/measure.js`）。全体の幅と高さは黒いシルエット（マスク）の外接矩形です。

**色の比率：** `tools/compare.py`。参考は x340–1335 / y95–735 の範囲で、背景（白に近く彩度の低い画素）と、タコに重なる注記ラベル 3 つを除きました。レンダリングはマスクで本体の画素だけを正確に切り抜いています。分類は次のとおりです。

| 暗部密度 | 輝度 < 80 |
| 暗い機械構造 | 輝度 < 110、彩度 < 0.3、緑以外 |
| 白い装甲 | 輝度 > 175、彩度 < 0.12 |

### 採点の内訳（(m) = 計測から計算 / (j) = 目視の判定）

closeness(d) = max(0, 100 − 2|d|)。d は参考との差（%）。

1. (m) 5 つの closeness の平均：本体/全幅、ドーム高さ、根元径、高さ/幅、触手 3 本の長さ（平均）。ラウンド2で長さ以外は 78〜91 点まで上がりましたが、横向きと手前の触手の長さが +40〜47% 離れており（長さの項目は 32 点）、全体を下げています。
2. (m) 70 ×（参考の配置に合う本数 / 8）+ 0.3 × 巻きの closeness − (j) 先端の形の減点。配置は改善前 5/8（左右の 2 本が床にあり、1 本が奥向き）→ 8/8。減点：ラウンド1は手前の先端が拳状で −15、ラウンド2は開いた鉤になったが参考より太く −10。
3. 25（各触手 12〜16 節）+ 25（全関節にリングと軸ピン）+ (j) 0〜50 の重なった非玩具的な装甲。改善前 20（白黒の縞）→ R1 30（後端のリップが重なる・灰色の下板）→ R2 35（パネルの継ぎ目・関節の緑ライン）。参考の多層プレートと真鍮の細部には届いていません。
4. 50 × ドーム高さの closeness ＋ (j) 透明で内部が読める 45/50（ガラス下部の反射がやや弱い）。
5. (j) 30（参考構図でコアが見える）＋ グロー 15→20（参考は球の中心で大きく光る）＋ 内部の豊かさ 30→32（真鍮ギアと緑の照り返しを追加、まだ参考より暗い）。

## 6. ラウンドの記録

### ラウンド 1（P0・P1：構造とシルエット）

**変更**
- ガラスを極角 93° → 103° まで広げ、カラーを赤道の 0.2 下へ移動。内部機構を 1.08 倍にして下げた
- 触手を参考の配置に合わせた：上に 2・横に 2（中段の高さ）・手前に 4。奥向きをなくした
- 付け根の径を 0.40 → 0.46 にし、細り方をゆるくした（中間 0.73・巻き始め 0.46・先端 0.25）
- 装甲を後端のリップが重なる形にし、灰色の下板を追加、関節リングをチタン色に
- カメラのハウジングを 0.42 → 0.34 に縮め、前へ突き出す筒形にして、少し下げた（極角 101 → 106°）

**理由：** 改善前の計測で、ドーム高さ −21%、カメラ +34%、配置 5/8、暗部 1.39 倍が出たため。

**結果：** ドーム高さ −4.7%、カメラ +8.7%、配置 8/8、暗部 1.09 倍、スコア 70.0 → 73.7

**悪化と対処**
- 最初の配置では本体/全幅が +17% になった（広がり不足）→ 横と持ち上げの触手を 15〜25% 伸ばして −7.3% に戻した
- 白が 1.38 倍、緑が 0.70 倍に悪化し、項目 6・9・10 が下がった → ラウンド2で対処

### ラウンド 2（P1：質感・配色・細部）
